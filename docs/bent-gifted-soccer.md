## Unordered List

**Markup**

```Markdown

* Level 1 item - 1

  * Level 2 item - 1.1

  * Level 2 item - 1.2

* Level 1 item - 2

  * Level 2 item - 2.1

    * Level 3 item - 2.1.1

    * Level 3 item - 2.1.2

  * Level 2 item - 2.2

```

::elCard{header="Result" header-class="font-bold"}

* Level 1 item - 1

  * Level 2 item - 1.1

  * Level 2 item - 1.2

* Level 1 item - 2

  * Level 2 item - 2.1

    * Level 3 item - 2.1.1

    * Level 3 item - 2.1.2

  * Level 2 item - 2.2

::

## Ordered List

**Markup**

```Markdown

1. Ordered item 1

   1. Ordered subitem 1.1

   2. Ordered subitem 1.2

2. Ordered item 2

   1. Ordered subitem 2.1

   2. Ordered subitem 2.2

      1. Ordered sub-subitem 2.2.1

      2. Ordered sub-subitem 2.2.2

```

::elCard{header="Result" header-class="font-bold"}

1. Ordered item 1

   1. Ordered subitem 1.1

   2. Ordered subitem 1.2

2. Ordered item 2

   1. Ordered subitem 2.1

   2. Ordered subitem 2.2

      1. Ordered sub-subitem 2.2.1

      2. Ordered sub-subitem 2.2.2

::
